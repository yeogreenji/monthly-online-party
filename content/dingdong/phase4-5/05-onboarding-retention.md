# 05 — 첫 방문·자발적 재방문·이용자 유입 기획 v1.0
2026-11-27 | 로렌 | 기획 제안. 실제 이용 데이터 없음.
## 첫 5분 경험
| 시점 | 화면/행동 | 문구 | 성공 조건 |
|---|---|---|---|
| 0~30초 | 마을 입장, 체험/로그인 선택 | 차 한 잔도 파티가 되는 동네에 어서 오세요 | 체험 진입 명확, 계정 전용 기능 설명 |
| 30~90초 | 동물 캐릭터 선택, 닉네임, 선택적 취향 | 오늘은 어떤 모습으로 놀러 갈까요? | 기존 캐릭터 선택/수정 유지, 취향 선택 건너뛰기 |
| 90~180초 | 광장 벨의 짧은 안내, 지도 | 카페부터 들러볼까요? 아니면 마음에 드는 문을 열어봐요. | 안내 건너뛰기, 직접 입장/조작 |
| 180~300초 | 공간별 오늘의 활동과 상시방 | 지금 열려 있는 이야기 / 혼자 즐길 거리 | 실제 사람 없는 방은 솔직히 표시, 로컬 콘텐츠와 구분 |
시간은 설계 목표이지 실측 결과가 아니다. 로그인 전후 저장 데이터 병합/삭제 확인. 복잡한 튜토리얼 강요 금지.
## 홈/광장 추천 영역
오늘의 파티(날짜 기반 기획/실제 개설 구분), 관심 공간, 친구가 공개 동의한 접속 상태, 최근 방문, 저장 모임, 내 집. 빈 공간은 가짜 이용자 대신 "아직 열린 모임이 없어요. 첫 모임을 열거나 모카와 이야기해 봐요." 추천 이유: "저장한 취미와 관련된 모임". 추천 안 받기·관심사 삭제.
## 세 가지 이용 루프
- 5분 혼자: 집 꾸미기→코디 저장→카페 NPC 인사→자유 종료.
- 20분 소셜: 오늘의 모임→실제 정원 확인→수다/게임→선택적 티켓 저장→친구 신청(선택).
- 주말/시즌: 축제 초대장→참여 일정 선택→실제 입장→네컷/선물(선택)→앨범.
어떤 루프에도 출석 점수, 연속 접속 손실, 가짜 마감, 의무 알림, 친구 강요 없음.
## 초대·공유
- 친구에게 공유할 공개 모임 카드: 모임 제목, 공간, 실제 일정/시간대, 참여 조건, 공식 링크, 실제 정원 상태. 비공개 모임은 초대 권한 확인 및 토큰 만료/철회.
- 자체 캐릭터 코디 카드/내 방 스냅샷/딩동 네컷/파티 티켓/시즌 엽서. 저장 전에 타인 닉네임·사진·말풍선 숨기기 기본, 별도 동의 시에만 포함.
- 공유 문구: "오늘 딩동에서 만날래? 차 한 잔도 파티가 되는 작은 동네야." / "내가 꾸민 방이야. 너도 놀러 와!" / "좋아하는 아티스트 이름으로 팬 모임을 열었어." 실제 서비스 주소는 배포 검증 후 삽입.
- 공개 홍보 소재: 15초 마을 산책, 15초 코디 변신, 15초 크리스마스 파티, 15초 팬 모임 개설, 15초 친구 네컷. 실제 기능만 촬영, 가상 주민/시연은 명시.
## 알림 원칙
초대·친구 요청·선물·편지·예약 모임 알림은 개별 동의. 마케팅/재방문 알림 기본 비활성화, 언제든 해제. 알림 예: "저장한 파티가 곧 시작해요. 오늘은 쉬어도 괜찮아요." 정확한 시작 여부/참가 상태는 서버 확인. 방해금지 및 빈도 제한(초기 제안 하루 최대 1개 홍보성 알림, 수신 동의 전 0개).
## 초기 베타 유입 가설
초기 참여는 사용자 동의 기반 친구 초대 및 공개 커뮤니티에서 허용된 방식의 홍보. 무단 메시지, 스팸, 가짜 리뷰·회원·협찬 금지. 첫 1주: 공간 진입과 채팅 UX / 둘째 주: 재방문 이유 / 셋째 주: 모임 및 소셜 기능 / 넷째 주: 유지 또는 수정 판단. 날짜는 공개 승인 후 확정.
## 최소 측정 설계
동의·보관 기간·식별자 최소화 검토 후 구현. 원문 메시지, 친구 사적 편지, 상세 주소, 실제 생년월일 등을 분석 로그에 저장하지 않음.

D1/D7 재방문율 = 첫 방문 코호트 중 각각 1일/7일 후 실제 재방문한 고유 이용자 ÷ 해당 코호트 고유 이용자 × 100. 집계 시간대 서울, 분모 0은 N/A. 초기 데이터 부족 시 숫자 단정 금지. 오류·이탈과 함께 질적 피드백 분석.
## 수용 조건
새 사용자/재방문/빈방/오프라인/실제 서버 오류 경로, 계정 동기화, 공유 동의 철회, 차단 이후 초대 거부, 알림 끄기, 추천 해제. 목표는 이용자 반응에 따라 수정.

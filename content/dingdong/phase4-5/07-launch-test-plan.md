## 출시 게이트
- G0 콘텐츠 통합: 승인 데이터 및 기존 ID 유지, 누락/중복/실제 연결 상태 확인.
- G1 서버 핵심: 로그인, 실제 채팅, 모임 공유, 정원 및 권한 검증. 독립 계정 최소 2개(정원 검증은 20+1 별도 계정/테스트 세션). 실패 시 공개 보류.
- G2 소셜: 미니룸·친구·방문·DM·신고·차단·삭제. 차단/권한·동의 철회·직접 접근 검증. 잠긴 성인 공간은 안전 승인 전 유지.
- G3 실기기: Android/iOS/PC/태블릿에서 실제 화면·키보드·터치·메모리·프레임·로딩·재접속 측정. 실측하지 않은 목표는 결과로 표시 금지.
- G4 공개 승인: 약관·개인정보 처리방침 및 운영자 대응·서버 무료 한도·상업 조건·권리 확인. 사용자 승인 후에만 소규모 베타.
- G5 사업화: 실제 이용 반응과 안전 운영 검증, 협찬 계약 및 비용 사용자 승인. 가짜 협찬/매출 금지.

## 결과 기록 양식
ID / 날짜·시간 / 커밋·브랜치·배포 URL / 브라우저·기기·서버 환경 / 계정 수 / 실제 절차 / 기대 결과 / 관측 결과 / PASS·FAIL·BLOCKED·NOT_RUN / 증거 로그·스크린샷 / 오류 심각도 / 수정 커밋 / 재검증. 실제 개인정보는 제거.
심각도 제안: P0 권한/개인정보 유출·데이터 손실·결제/안전 중대 위험 → 즉시 공개 중지. P1 핵심 로그인/채팅/정원 실패 → 해당 출시 보류. P2 주요 UI/기능 오류 → 수정 후 재검증. P3 장식/문구 → 백로그. 최종 결정 사용자.
## 베타 운영 제안
초기 초대형 소규모 성인 베타, 4주(1주 입장·조작, 2주 채팅·파티, 3주 친구·미니룸, 4주 재방문 및 개선). 실제 인원과 일정은 사용자 승인 후 확정. 가입·탈퇴 자유, 문제 신고 경로 명확. 지원 가능한 운영 시간 안내, 자동 응답을 실제 운영자처럼 표시 금지.
질문: 처음 이용할 때 헷갈린 부분? 가장 즐거운 공간? 혼자/친구와 이용 차이? 다시 들어올 이유? 불편·불안했던 점? 추가 원하는 활동? 선택적 응답, 개인정보 수집 최소화.

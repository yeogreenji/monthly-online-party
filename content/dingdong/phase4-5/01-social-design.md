# 01 — 소셜 콘텐츠 및 이용 흐름 상세 설계 v1.0
2026-11-27 | 로렌 | 기획 제안, 구현 대기. 승인된 콘텐츠 마스터의 상세화이며 새로운 운영 수치·정책은 검토안이다.
## 핵심 원칙
대화, 친구 맺기, 공개, 기록, 선물은 모두 선택. 실제 이용자와 가상 주민 명확히 구분. 기본 비공개. 기존 기능/ID 유지. 개인정보 최소 수집, 서버 권한을 화면 표시와 독립 검증. 연령 확인 전 잠긴 공간 유지.
## 1. 친구 찾기와 관계
- 광장/모임의 실제 사용자 캐릭터 터치 → 작은 프로필(닉네임, 캐릭터, 공개한 취향, 상태) → 친구 신청 / 신고 / 차단. 개인정보·보유 연락처·정확한 위치 표시 금지.
- 검색은 닉네임 기반, 정확한 일치 및 선택적 검색 노출 설정; 동일 닉네임은 내부 식별자로 분리. 사용자 목록에 NPC 섞지 않음.
- 관계 상태: 없음 → 요청 보냄 → 수락/거절/취소 → 친구 → 해제. 차단은 독립이며 양방향 노출·DM·방문·선물·초대·신청 제한. 차단 해제 후 자동 친구 복구 금지.
- 문구: "친구 신청을 보냈어요" / "○○님이 친구가 되고 싶대요" / "수락하면 서로 친구가 돼요" / "친구 신청을 받지 않는 주민이에요". 상대 거절 사유 미노출.
- 수용: A 신청/B 수락 후 양쪽 친구 목록; 중복/자기 신청 거부; B 차단 시 A의 직접 주소 접근도 실패; 로그아웃 후 상대 비공개 정보 미노출.
## 2. 내 집과 방문
- 내 집 탭: 미니홈피·집 꾸미기·옷장·사진첩·방명록·우편함. 소개/기분/공식 음악 링크/취향 태그/선택한 참여 기록은 항목별 private/friends/public. 처음은 private. 공개 전 어떤 항목이 보이는지 미리보기.
- 문 상태: 닫힘(기본) / 친구에게 열림 / 초대받은 친구만. 문 열림은 설정한 허용 관계와 공개 범위를 넓히지 않는다. 집주인 부재 중 방문 허용은 별도 opt-in; 편집 권한은 소유자만.
- 친구 집 → 방문하기 → 권한 확인 → 현관 → 초인종(옵션) → 입장 → 앉기/인사/방명록/허용 선물 → 나가기. 방문 중 집주인이 문 닫으면 광장으로 안전 복귀.
- 문구: "지금은 혼자 쉬는 중이에요" / "친구가 문을 열어뒀어요" / "딩동! ○○님이 놀러 왔어요" / "방문을 마쳤어요". 실제 소유자/접속 여부만 표시.
- 수용: 두 계정 저장·재접속, 미허가 읽기/수정 거부, 로그아웃·차단·친구 해제 즉시 권한 철회, 공개 범위 변경 후 사진 URL 직접 접근도 거부.
## 3. 방명록·편지·DM·초대
| 종류 | 기본 범위 | 흐름 | 콘텐츠 예시 |
|---|---|---|---|
| 방명록 | 친구, 소유자 설정 | 방문→작성→전송→소유자 삭제/신고 | 오늘 방 너무 예뻐요! |
| 편지 | 수락 친구 | 우편함→받는 사람→짧은 글→전송 | 오늘 같이 놀아서 즐거웠어요. |
| DM | 별도 상호 동의 | 요청→수락→텍스트 대화→동의 철회 | 다음에 딩동 카페에서 또 만나요. |
| 초대장 | 친구/허용한 모임 | 파티 선택→친구 선택→발송→수락/거절 | 오늘 저녁 창가 독서회 어때요? |
| 미래 편지 | 본인 전용 | 작성→도착일→저장→수정/취소→읽기 | 한 달 뒤의 나에게. |
- DM은 초기 텍스트, 연락처/외부 만남 유도 제한 유지. 메시지 실패 상태·재시도·중복 방지, 알림 차단, 메시지 신고 증거 보존 범위 별도 정책 검토. 수신 철회 후 새 전송 불가.
- 초대는 자리를 자동 예약하지 않음; 수락 시 실제 서버 정원 확인, 만석이면 대기/추가방 선택. 만료/취소 표시. 쪽지 수신 허용과 친구 수락을 동일시하지 않음.
- UI 빈 상태: "아직 편지가 없어요. 혼자 쉬어도 좋은 날이에요." 오류: "보내지 못했어요. 내용은 남겨뒀어요." 금지: 가짜 메시지/인기 수치.
## 4. 무료 선물 및 초인종
20종은 master 카탈로그 유지. 보내기: 친구 선택 → 선물 → 선택 메시지 → 미리보기 → 전송 → 수신함 → 받기/숨기기/신고. 받은 아이템의 전시/인벤토리는 수신자 선택. 재판매·현금 환전·확률·결제 없음.
선물 카드 예시: 튤립 "오늘도 좋은 하루였으면 해요" / 커피 "잠깐 쉬어가요" / 쿠키 "작은 간식 하나!" / 생일 케이크 "오늘의 주인공을 축하해요" / 별 조명 "당신의 방에 작은 별 하나".
초인종 6종은 기존 마스터 문구. 수신 설정: 방문/선물/편지/모임/생일/광장 각각 on/off; 효과음·볼륨·방해금지. 수신자 차단 및 서버 발송 제한 우선. 제안 제한: 동일 상대 선물 3회/일, 초인종 1회/분, 초대 3회/시간(베타 남용 측정 후 조정). DB 시간 기준, 중복 요청은 동일 결과; 사용자에게 횟수 제한 안내.
## 5. 함께 놀기 및 신규 8개 기능
| 콘텐츠 | 흐름 | 완료 판정 |
|---|---|---|
| 문 열어두기 | 공개 범위 → 방문 승인 → 현관 | 미허가 접근 불가 |
| 말없이 함께 있기 | 카페 빈 좌석 → 앉기 → 조용히 표시 → 자유 퇴장 | 채팅/응답 강제 없음, 실제 좌석/접속 동기화 |
| 파티 기념 티켓 | 참여 후 직접 저장 → 앨범 → 삭제 | 참여 사실·시간 서버 확인, 미참여자 티켓 허위 생성 없음 |
| 딩동 라디오 | 도레 소개 → 공식 링크/동의 사연 → 읽기 | 음원 재배포 없음, 공개 철회 가능 |
| 미래 편지 | 본인 작성/날짜 예약 → 도착 → 읽기 | 서울 시간, 본인만 조회 |
| 딩동 네컷 | 친구 초대 → 촬영 동의 → 4포즈 → 미리보기 → 저장/공유 동의 | 타인 이미지 무단 공유 방지, 거절/취소 경로 |
| 추억 상자 | 직접 저장한 활동/사진/편지 → 월별 필터 | 삭제 반영, 기본 비공개 |
| 작은 전시회 | 사진/작품 등록 → 공개 동의 → 검수 → 전시 → 철회 | 인기 순위 없음, 신고/저작권/위치정보 검증 |
## 6. 연결 우선순위
친구/공개 권한→계정 저장→집 방문→방명록/편지/DM→선물/초인종→함께 놀기→티켓/네컷→나머지. 서버 실연결·독립 계정 검증 전 로컬 시연 표시. 완료 보고는 화면/DB/테스트를 나누어 작성.
